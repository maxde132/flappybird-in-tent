**FlappyBird** in **Tent**
---
This is a simple flappybird script designed to run in the terminal. It is written in the amazing language of [Tent](https://github.com/35rod/tent) (plz star it).

`./tent flappybird.tent`

**Instructions**
---
once the script is lauched you type the direction you want to go. 
- **3** for straight
- **2** for down
- **1** for up
- **Ctrl-C** to exit the game
